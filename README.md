# DeepRead：Zotero AI 精读插件

DeepRead 是一个免费、开源的 Zotero 插件，支持 Zotero 7–10。它把 Vibero 的 AI 精读能力做成了普通插件，可以直接装进官方 Zotero 使用：

- **不需要账号、积分或订阅。** 解析和大模型服务都用你自己的 API Key。
- **PDF 内容只发往你在设置里配置的服务。** 插件不会连接其他任何服务器。

当前版本 **v1.0.1**，各版本的改动见 [更新日志](CHANGELOG.md)。

## 快速上手

1. 从 [Releases](https://github.com/solsongli/deepread/releases/latest) 下载 `deepread-x.y.z.xpi`，在 Zotero 的「工具 → 插件」里从文件安装（详见下方「安装」）。
2. 打开「设置 → DeepRead」，选一个大模型预设，填入 API Key，点「测试连接」。PDF 解析默认使用内置解析，不需要额外配置。
3. 打开一篇 PDF，点工具栏上的「AI 精读」。完成后：
   - 页边卡片会显示每一段的摘要和 AI 讲解，并用彩色标签标出这段的作用（背景、方法、结果等）；
   - 工具栏下方的全文结构条显示各章节和阅读进度，点击可跳转；
   - 每张图表旁边有一张图表卡片，附 AI 写的读图步骤；
   - 鼠标停在段落上会显示译文：双栏论文显示在另一栏的同一高度，单栏论文显示在该段下方，大小和原段一样；
   - 单击段落，会展开它的卡片；
   - 在卡片上点「✎」可以写下「我的理解」，点「卡」可以生成闪卡，点「AI」可以就这一段提问；
   - 横条上的「阅读深度」可切换全文 / 重点 / 只看边注；鼠标停在引用、图表引用、术语或符号上会弹出说明；侧栏「阅读问题」给出 5 个问题和答案出处；
   - 「带读」默认关闭，可在「功能」菜单启用，让 Agent（本地 Codex / Claude Code、远程 API 或导入的结果）带你按 定位 → 骨架 → 方法 → 证据 → 带走 五步读；
   - 工具栏的「功能」菜单可以逐项打开或关闭这些功能。

## 功能

| 功能 | 说明 |
|---|---|
| **「功能」菜单** | 阅读器工具栏上的「功能 n/m ▾」可以逐项勾选：页边卡片、悬停翻译、要点高亮、全文结构条、图表卡片、速读分层、悬停查证、问题导向、带读。<br>• 菜单顶部选「仅本文」只改当前论文，选「设为默认」改所有论文的默认设置<br>• 卡片字号和宽度、重新精读、生成 AI 讲解、设置、删除本文精读结果也在这里 |
| **AI 精读** | 在阅读器工具栏点「AI 精读」，插件会依次完成以下步骤：<br>• 解析 PDF 结构<br>• 把每个段落对齐到原文位置<br>• 逐页调用大模型，为每段生成摘要和要点，并给出每个要点的翻译<br>• 再逐页为每段写一段「AI 讲解」（用通俗的话讲这段在说什么、为什么重要、关键术语和符号的含义），边生成边填进页边卡片 |
| **悬停段落卡片** | 关闭页边卡片时，鼠标停在段落上，旁边会弹出卡片，显示段落摘要、AI 讲解、要点和折叠的译文：<br>• 悬停某个要点，会高亮它在原文中对应的句子<br>• 点击要点可以切换重要度（普通 / 蓝色 / 红色），重要的要点会在 PDF 中一直高亮显示 |
| **悬停翻译** | 鼠标停在段落上，该段会加框，并显示译文，不遮挡原文：<br>• 双栏论文：左栏段落的译文显示在右栏同一高度，右栏段落的译文显示在左栏<br>• 单栏论文：显示在段落正下方（下方放不下时显示在上方）<br>• 译文宽度、行距和缩进参考原文；字号不超过原文，过长时最多缩小到 85%，仍放不下则自然增高<br>• 新生成的译文根据 PDF 字符字体保留粗体／斜体范围；图注单独定位，不再按图片高度放大文字<br>按住 `Alt` 临时隐藏；拖动选字时不显示。可在「功能」菜单里关闭 |
| **点击段落打开卡片** | 精读后单击 PDF 里的段落，页边上该段的卡片会展开成完整卡片，并滚动到可见位置；还没有 AI 讲解的段落会当场生成。单击页面空白处收起。关闭页边卡片时，改为在段落旁固定显示悬浮卡片 |
| **速读卡** | 右侧栏显示 5 部分速读卡：论文标题、研究背景、核心创新点、实验结果、结论与价值。点击其中的要点，会跳回它对应的原文 |
| **AI 大纲** | 右侧栏按需生成层级大纲，每一节附一句总结，点击可以跳转到该节 |
| **AI 对话** | 基于全文（含页码）回答问题：<br>• 同时参考每段的 AI 讲解和你写的「我的理解」，回答会引用对应的段落块，如 `(p. 3 ¶2)`，点击即跳到该段并打开它的卡片<br>• 回答里的 `(p. N)` 可以点击跳转<br>• 支持 Markdown 和 LaTeX 公式<br>• 对话按文献保存在本地 |
| **页边卡片** | 默认开启，可在「功能」菜单中关闭。开启后：<br>• 每张卡片对齐对应段落，滚动和缩放时跟随。卡片主体是这一段的 AI 讲解，下面是要点；译文作为一部分默认折叠，点「▸ 译文」展开（可在设置里改为默认展开）<br>• 连续几段讲同一件事时，AI 会把它们合并成一张卡片（标题旁标着「2 段」等），单击其中任一段都会打开这张卡片；可在设置里关闭<br>• 默认「卡片保持展开」：打开的卡片不会因为点了别处而收起，单击卡片标题收起；「功能」菜单里可以一键收起全部<br>• 左右卡片栏顶部的小按钮可以把卡片栏收成一条窄边（例如打开右侧 AI 对话时），点窄边恢复<br>• 卡片左上角的彩色标签标出这段的作用：背景、空白、已有工作、贡献、方法、结果或局限，卡片头部也按角色着色。折叠的卡片会显示「闪卡 N」「理解」小标记<br>• 卡片分布在 PDF 两侧：左栏段落的卡片在左边，右栏段落的卡片在右边；单栏论文只用右侧。可在「功能」菜单或设置里改为全部放在右侧<br>• 卡片字号和宽度可在「功能」菜单或设置里调整，也可以拖动卡片栏靠近 PDF 的边缘调宽<br>• 单击摘要展开或收起卡片；双击摘要可以直接编辑；「讲」重新生成 AI 讲解<br>• 悬停卡片会在原文中高亮对应段落<br>• 卡片可以隐藏，隐藏后可在菜单里恢复。之前精读过的论文可在「功能」菜单里点「生成 AI 讲解」补上 |
| **速读分层** | 横条上的「阅读深度」：<br>• 全文：正常显示<br>• 重点：次要段落淡化，重点段落的关键句加下划线，次要卡片收成一行<br>• 只看边注：正文淡化，所有卡片收成一行摘要<br>• 显示本页和全文的预计阅读时间；「下一个重点 ↓」或按 `N` / `Shift+N` 在重点段落之间跳转；「读图…」直接选择图表，先核对图注与证据 |
| **悬停查证** | 和页边卡片互相独立。鼠标停在：<br>• 引用编号上：显示参考文献的标题、作者、年份和本文引用次数；如果已在你的 Zotero 文库中，可以直接打开<br>• 「Fig. 3」「Table 1」上：显示图表缩略图和读图步骤<br>• 术语或符号上：显示 AI 整理的定义和首次出现位置<br>• 侧栏「术语与符号」列出全部术语和符号 |
| **问题导向** | 精读后 AI 回答 5 个阅读问题（要解决什么问题、方法核心、关键设计、证据、局限），并标出答案所在段落：<br>• 侧栏「阅读问题」：点段落标签跳到原文；可以输入自己的问题<br>• 卡片上显示 Q1、Q2 等标记，结构条上标出答案位置<br>• 工具栏「问题 n/5」显示已读到答案的问题数；可以设置读到时再揭晓答案 |
| **带读** | 工具栏「带读」打开右侧的带读面板，五步：<br>• ① 定位：真正的主张、研究路径还原、阅读顺序、带着 3 个问题读<br>• ② 骨架：背景 → 空白 → 已有方案 → 贡献 → 主张，主张标出已证 / 部分 / 未证；术语账本<br>• ③ 方法：部件承重判断、核心思想三层、公式手算<br>• ④ 证据：证据链、边界检查、措辞强度<br>• ⑤ 带走：一句话总结、研究想法和 16 节精读卡，可存为 Zotero 笔记<br>每一条都链接到原文段落；带读的判断也显示在页边卡片上。由设置里的 ③ Agent 通道生成：本地 Codex / Claude Code（配合 nature-paper-xray、nature-paper-card 技能）、远程 API，或导入现成结果 |
| **荧光笔** | 单击卡片上的要点，会依次换成第 1、2……种荧光笔颜色，最后再点一次清除，PDF 里对应的句子也会用同一颜色高亮。颜色的数量（1–6 种）和颜色本身可在「功能」菜单或设置里修改 |
| **全文结构条** | 工具栏下方的一条章节横条：每节按篇幅占位、按类型着色（引言、方法、实验、讨论、参考文献等）。<br>• 已读部分用深色填充，右侧显示「已读 x%」，当前章节加描边<br>• 点击某一节，跳到该节标题 |
| **图表卡片** | 每张图和每个表格在旁边的页边生成一张卡片（图为琥珀色，表为青绿色），拆成多个子图的图会合并成一张：<br>• 图号、标题、正文提到它的次数和缩略图<br>• AI 写的 2–4 步读图步骤：先看什么、再对比什么、最后得出什么结论<br>• 单击正文中提到「图 3(b)」的段落，对应卡片会高亮，并标出与 (b) 相关的那一步<br>• 单击卡片跳到原图 |
| **我的理解** | 在页边卡片上点「✎」，可以写下自己对这一段的理解、疑问或联想：<br>• 「我的理解」始终展开显示，不会折叠<br>• 会和闪卡一起导出到 Zotero 笔记 |
| **闪卡** | 选中文字后点「闪卡」，或在段落卡片上点「卡」，AI 会出题并给出答案：<br>• 闪卡挂在对应段落的页边卡片里：AI 答案默认折叠，点击翻面；你给闪卡写的「我的理解」始终显示<br>• 「闪卡」面板支持复习模式、编辑、让 AI 生成答案、定位原文，以及一键导出为 Zotero 笔记 |
| **代码面板** | 自动从论文中识别 GitHub 仓库，也可以按标题搜索或手动粘贴地址：<br>• 查看仓库信息、README 和文件树<br>• 加载 DeepWiki 文档并向 DeepWiki 提问。问题和仓库名会发送到 deepwiki.com；GitHub Token 是可选的 |
| **选段翻译 / 问 AI** | 选中文字后，弹出菜单里多出两个按钮：<br>•「翻译」：显示译文后可以复制，或存为高亮批注<br>•「问 AI」：把选中内容作为引用发进 AI 对话 |

## 安装

1. 从 [Releases](https://github.com/solsongli/deepread/releases/latest) 下载最新的 `deepread-x.y.z.xpi`。
2. 在 Zotero 中打开「工具 → 插件」，点齿轮图标，选「从文件安装附加组件…」，然后选中这个 `.xpi` 文件。

之后会自动更新：Zotero 大约每天检查一次插件更新。想立即更新，可以在「工具 → 插件」里点齿轮，选「检查更新」。

也可以自己构建：`npm install && npm run vendor && npm run build`，产物在 `build/` 目录下。

## 配置（设置 → DeepRead）

设置页分为三个通道：① 精读 API、② 文档解析、③ Agent，另有「功能模块」和「阅读」两组选项。

### ① 精读 API

任何 OpenAI 兼容接口都可以用。插件内置了以下服务的预设：

- DeepSeek
- 阿里云百炼
- 智谱
- 火山方舟
- 硅基流动
- OpenRouter
- OpenAI
- Ollama 本地

选好预设后填 API Key 即可，然后点「测试连接」确认。

可以保存多组配置（例如一组 DeepSeek、一组本地 Ollama），点配置卡片即可切换，类似 CC Switch。用「+ 添加」「复制」「删除」管理配置，在「配置名称」里重命名。精读、AI 讲解、图表卡片、闪卡、翻译和对话都使用当前选中的配置。

关于「JSON 模式」：

- 默认选 `json_object`，兼容性最好。
- 如果服务商支持严格 JSON Schema，可以改成 `json_schema`。
- 如果服务商不支持你选的模式，插件会自动降级。

### ② 文档解析

有四种方式，点卡片选择，默认使用内置文字层：

- **内置文字层（推荐）**：直接用 PDF 自带的文字层识别段落、标题、图表和公式。不需要任何服务，免费、离线、一篇论文约 1 秒。扫描版 PDF 没有文字层，无法使用精读功能。
- **GROBID 本地服务**：专为学术论文设计，只需 CPU 和约 1–2 GB 内存。用 Docker 启动：`scripts/grobid.sh start`（当前用户需要在 docker 组里）。服务地址默认是 `http://127.0.0.1:8070`。
- **MinerU 官方 API**：在 <https://mineru.net/apiManage> 申请 Token 后填入。免费额度以官网为准。
- **自建或第三方 MinerU 兼容服务**：填入 `mineru-api` 的地址（插件会调用 `POST /file_parse`）。如果服务需要鉴权，再填 Token。

选中的服务连不上或出错时，会自动改用内置文字层，精读不会中断。

### ③ Agent（带读）

「带读」由这个通道生成，四种方式任选：

- **Codex / Claude Code（本地）**：点「带读 → 运行带读」后，DeepRead 在数据目录下建一个工作目录，写入论文文本 `paper.md`（每段带 `[p. 3 ¶2]` 标签），再运行本机的 Codex 或 Claude Code。Agent 按勾选的技能（默认 nature-paper-xray、nature-paper-card）写出 `xray.md` 和 `paper-card.md`。
  - 默认命令：`codex exec --skip-git-repo-check --sandbox workspace-write --cd {workdir} {prompt}`，以及 `claude -p {prompt} --permission-mode acceptEdits --allowedTools … --add-dir {skills}`。
  - 「命令」一栏可以改成完整路径或自己的参数，`{prompt}`、`{workdir}`、`{skills}` 会被替换。
  - Agent 用它自己的账号和模型，PDF 只在本机交给它。
- **远程 API**：填一个 OpenAI 兼容接口和模型（可以和精读 API 不同，例如更强的推理模型），一次请求写出长文和精读卡。
- **导入**：选择一个已有的精读卡 / 长文 Markdown，或 DeepRead 的带读 JSON。
- 生成的 Markdown 最后由「精读 API」整理成五步，并对应到原文段落。

「检测」会检查命令和技能文件是否存在，不会运行任何程序；只有在带读面板里点「运行带读」才会启动 Agent。超时默认 10 分钟。

### 功能模块与阅读

- **功能模块**：页边卡片、悬停翻译、全文结构条、图表卡片对所有论文的默认开关。单篇论文可以在阅读器工具栏的「功能」菜单里单独打开或关闭。
- 选择摘要、讲解和翻译的输出语言。
- 选择是否显示高亮和悬停卡片。
- 页边卡片：卡片宽度（200–520 px）、卡片字号（10–18 px）、卡片位置（自动，或全部放在右侧）、精读后是否自动生成每段的 AI 讲解、卡片是否保持展开、是否把相关段落合并为一张卡片、荧光笔颜色、译文是否默认展开。

## 费用参考

- **PDF 解析**：内置解析和 GROBID 都免费。只有使用 MinerU 官方 API 时，才按页计费或计入免费额度。
- **大模型**：
  - 精读：每页 1 次请求生成摘要、要点和译文；另有 1 次请求生成速读卡，1 次请求过滤作者信息块。
  - AI 讲解：精读后每页再发 1 次请求（可以在设置里关闭自动生成）。单段重新生成或补生成，每段 1 次请求。
  - 图表卡片：精读后为全部图表生成读图步骤，每 6 张图表 1 次请求。关闭图表卡片就不会发送。
  - 问题导向：精读后 1 次请求生成 5 个问题；自己提的问题每个 1 次请求。
  - 悬停查证：精读后 1 次请求整理术语与符号表；引用和图表查证不需要请求。
  - 带读：本地 Codex / Claude Code 用它们自己的账号计费；远程 API 每次带读 1 次（较长的）请求；之后精读 API 再用 1 次请求整理成五步。导入结果只需要整理这 1 次。
  - 闪卡：每生成一张 1 次请求。选段翻译：每次 1 次请求。
  - AI 大纲需要你手动生成，每次 1 次请求。
  - AI 对话每发一句消耗一次请求。上下文默认最多带 12 万字符，包括全文和各段的 AI 讲解；可以在设置里调小。

## 数据存放

| 数据 | 位置 |
|---|---|
| 精读结果、AI 讲解、读图步骤、阅读问题、术语与符号、带读、我的理解、闪卡和对话 | Zotero 数据目录下的 `deepread.sqlite` |
| PDF 解析结果（`content_list.json`、`full.md`） | Zotero 数据目录下的 `deepread/mineru/<库ID>_<条目Key>/` |
| 带读的工作目录（`paper.md`、Agent 写出的 `xray.md`、`paper-card.md`） | Zotero 数据目录下的 `deepread/agent/<库ID>_<条目Key>/<时间>/` |
| API Key | Zotero 本机偏好设置，以明文保存 |

要删除某篇文献的结果，在工具栏「功能」菜单中选「删除本文精读结果」。

