# 引用与图表悬停查证

查证只处理原文中的参考文献和图表引用，不请求模型，也不重新引入术语、符号、闪卡或代码面板。

- 每次鼠标移动、关闭、滚动、禁用功能或离开阅读器都会使旧 PDF 字符查询失效。迟到的结果不会重新弹出，也不会覆盖后来指向的引用。
- 从一个引用移到另一个引用时，旧弹层的关闭计时器不会取消新的悬停查询。鼠标或键盘焦点进入弹层后，保留当前内容，支持查看、复制和打开原文献。
- 弹层提供关闭按钮和 Esc。关闭后，在鼠标离开该引用之前不自动重弹；点击其他位置、滚动原文和窗口尺寸变化也会关闭弹层。
- 弹层和图表缩略图适应阅读区的实际宽高，长内容在框内滚动。异步补充“已在文库”信息后会重新校正位置，深色主题保留可见的焦点边框。
- 开始查证时暂时收起当前段落的悬停译文，使原文引用保持可见；译文弹层内的文本不会被当成它下面的 PDF 引用。
- “已在文库”只在规范化 DOI 或完整标题匹配时出现。有 DOI 的候选如果与引用的 DOI 冲突，不会只凭同名标题匹配。标题回退须得到唯一候选，或所有候选具有同一个已知 DOI；多个不同 DOI、缺失 DOI 的同名条目不自动择一。仅缓存已核对的 DOI 匹配，导入新条目后会重新检查标题歧义和此前未找到的引用。

测试入口：

```bash
node test/lookup.test.mjs
python3 -E test/build-lookup-fixture.py
env -u PYTHONHOME -u PYTHONPATH \
  E2E_BASE="$PWD/.test-profile/lookup-ux" E2E_SKIP_SERVICES=1 \
  E2E_PDF="$PWD/test/fixtures/reading/lookup.pdf" \
  scripts/e2e.sh test/e2e/lookupUX.js
```

单元测试覆盖异步竞态、引用切换、取消和文库匹配；原生测试使用构造 PDF 的真实字符坐标，以及 Zotero DOM 的尺寸、焦点、主题和模块开关。没有调用远程模型，也没有证明真实读者的效率提升。
