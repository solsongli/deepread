# 阅读界面的视觉规范

2026-11-05，v1.4.0。

以 PDF 原文为阅读中心，辅助区使用克制的中性色背景、清楚的文本层级和可辨认的文字操作。保留用户此前要求的角色颜色区别，避免所有信息都使用主操作色。

| 用途 | 表现 |
| --- | --- |
| 主操作、出处、键盘焦点 | 蓝色；使用文字说明，控制焦点边框 |
| 自己的解释与笔记 | 绿色标签、浅色背景、独立的笔记区域 |
| 待弄懂 | 琥珀色及明确的按下状态 |
| 段落角色 | 保留七种实色标签与 4px 色条，标题背景轻度着色 |
| 正文 | 统一无衬线界面字体、充足行距；译文继续保持原文结构和字体度量 |
| 低频操作 | 放在「更多」菜单，隐藏操作与常规操作分隔 |

## 样式归属

`addon/content/styles/theme.css` 只定义 DeepRead 命名的变量和公共菜单样式，不重绘 Zotero 原生界面。`ui.js` 分别将主题安装到主窗口、reader 文档、PDF 文档；CSS 变量不会跨 iframe 自动继承。明确的 `data-color-scheme` 优先，主窗口没有明确主题时使用系统颜色偏好。系统要求减少动态效果时关闭插件内过渡。

页边卡片样式移到 `rail.css`，侧栏使用 `panes.css` 和 `questions.css`。卡片默认 13px，明确保存过的字号仍生效；200px 卡片栏配合 18px 字号时，操作行允许换行。固定于宿主的 41px 工具栏高度保持兼容，结构条继续按真实内容高度为 PDF 留出空间。

## 操作与焦点

常用操作是「笔记 / 提问 / 更多」。每个原段落的出处与待弄懂按钮仍成组显示，合并卡片不丢失原段落身份。

卡片菜单挂在 reader 文档中，避免被卡片的滚动容器裁切；限制在可见窗口内。方向键、Home／End 选择菜单项，Esc 返回触发按钮。编辑摘要转移到编辑器；合并／拆分后定位相应卡片；隐藏后返回 PDF。背景重建、卡片移除、阅读器卸载以及跨 iframe 点击都清理菜单和监听器。Gecko 的不同 document wrapper 通过 DOM 节点身份匹配，卸载另有统一清理。

功能菜单使用包含原生控件的非模态设置面板，按显示功能、版面与标记、论文操作分组。完整内容可滚动，作用范围保持可见。

## 验证

原生 Zotero 测试使用隔离资料库及构造 PDF。`visualDesign.js` 覆盖主题安装、菜单键盘与生命周期、菜单里的原操作、200px／18px 边界和文字对比；`toolbarUI.js` 检查设置面板尺寸、滚动、焦点和关闭清理。原有问题侧栏、疑点、查证、卡片开合、翻译结构与结构条也分别回归。

另用四个实际侧栏 renderer 检查 355px 与 280px 的摘要、大纲、聊天和问题面板。截图是界面测试数据，不代表真实模型生成质量或用户学习效果。测试按有效对比度检查可读性，不锁定旧版本的具体 RGB 值。

最终 `npm test` 通过。八组 Zotero 10.0.6 原生回归共 201 项：视觉与卡片菜单 25、功能菜单 17、查证 18、问题侧栏 21、卡片交互 27、翻译版式 44、结构条 27、待弄懂记录 22。角色色条检查等待实际渲染；角色颜色不使用过渡，避免语义标签与色条在更新时短暂不一致。
