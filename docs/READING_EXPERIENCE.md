# 阅读体验改进：依据、实现与边界

调研日期：2026-10-27。目标：减少读论文时的遮挡、错误定位和来回查找，暂不扩展 Agent 带读。

## 阅读方法如何落地

| 依据 | 对本插件的启发 | 本轮处理 |
| --- | --- | --- |
| [Keshav, How to Read a Paper](https://stanford.edu/class/cs114/reading-keshav.pdf)：分遍阅读，先建立全貌，随后检查图表，再深入细节 | 浏览和精读需要不同的信息密度；图表是核对证据的入口 | 复用全文／重点／边注模式，增加「读图…」选择器；不增加独立带读流程 |
| [Scim, IUI 2023](https://arxiv.org/abs/2205.04561)：研究可按内容类型、分布和密度调整的速读辅助 | 辅助信息应可调节，不能让满屏强调代替判断 | 保留已有模式与开关；移除译文放大填框，默认关闭带读；未新增 AI 高亮规则 |
| [Semantic Reader Project, 2023](https://arxiv.org/html/2303.14334v2)：原位解释、导航与可访问阅读界面 | 少离开原文，减少上下文切换 | 保留段落、图注位置；图表直接跳转；继续复用既有引用／术语悬停查证 |

上表最后两列是设计判断，不是文献对 DeepRead 的效果证明。尚未做用户阅读速度或理解度实验。

## 具体修复

1. 原文样式：通过句子字符映射读取 PDF 粗体／斜体，把对应范围传给翻译模型；译文 Markdown 安全渲染为强调。中文标点紧贴后续正文时补全未解析的强调标记。保持原文基础字号、行距与缩进，无法保证跨语言逐字位置和换行完全一致。
2. 图注：原先图注没有字符映射，整张图的框被当作一行，导致大字号。现在在该页唯一匹配完整图注，保存文字字号并使用图注行框。无法匹配时保留图注内容，使用保守字号，不再拿图片高度当行高。
3. 图文混块：优先在 MinerU 范围内匹配完整原文，收紧到对应字符；必要时尝试移除明确图表范围内字符，只有剩余文本完整匹配原文时才采纳。字符映射不连续时分别计算矩形，避免把排除的图中文字重新加入命中区。
4. 图表阅读：已有速读条加入图表选择器，按索引跳到原图；无需新 API 请求。窄窗口隐藏阅读时间，保留主要操作。

## 使用与局限

后续阅读方法调研与本轮实现见 [READING_METHODS.md](READING_METHODS.md)。本轮进一步改为译文等宽、尽量等高，超出时滚动；增加连续片段自动合并、手动合并／拆开、再次点击原文收起、模型重要度高亮和旧缓存稀疏建议；移除术语与符号、闪卡、代码功能及请求，数据库旧内容保留。下文 v1.0.1 的实现记录描述第一轮修复。

- 旧缓存的图注大字号回退和不放大策略立即生效。粗体翻译、图注字符定位、混块重对齐需要重新精读；仅重新生成 AI 讲解不够。
- 扫描版、字体元数据缺失、OCR 与文字层不一致、重复图注无法唯一匹配时，保留原有内容。不是完整的版面识别模型，不保证纠正所有 MinerU 分块错误。
- 强调范围的跨语言映射仍由用户配置的翻译模型执行；已验证输入标记和显示链路，没有调用真实付费模型验证语义对齐。
- 带读默认关闭，用户显式保存的开关优先；已有带读结果不删除。

## 跨页与跨图续段（2026-10-28）

- 页码、文本范围、字体与图像位置只用于提出候选；模型再判断是否属于同一原始段落，并将原文片段一起翻译。不会把两个已有译文简单拼接。正文完整句也可能属于续段，普通换页不等于自动合并。
- 不跨章节、公式或列表边界；图注不进入正文联合翻译。浮动图片可来自解析列表，即使它不在文字之间的序列位置也能参与几何判定。
- 一组候选最多 6 处、12,000 个原文字符；每个请求最多 4 组。无法确认、无可用 API 或失败时保留原译文。模型的语义判断仍可能出错，保留「拆」作为纠正入口。
- 两端原文坐标独立，高亮不覆盖中间图片。译文框按两端文字总高度适配（最长半个可见阅读区域），不计入图片空白；过长时滚动。卡片只展示一次联合译文。
- 旧结果在打开后自动补齐；成功检查状态保存到本地，不重复请求。请求失败后下次打开可重试，取消／重新精读不会写入迟到的结果。
- 验证使用构造的两页 PDF、真实 PDF.js 字符及本地模拟模型响应；单元测试及 22 项隔离 Zotero 检查覆盖跨页、跨图、反例、取消、格式保留、保存重载和旧缓存升级，未调用真实模型评估语义判定准确率。
